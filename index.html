❓ How it works

Review before dispatch
ImageXpert prepares a per-engine queue. You choose when each external search page opens.

Choose the source path

  1. Public URL: the URL is placed directly into supported engine requests.
  2. Local-only file: hashes and edits stay here; manual engine upload pages are queued.
  3. External upload: after session-only consent, the file becomes a public Litterbox URL for one hour and selected engines receive that URL.
  4. Video: selected keyframes become local image tasks and follow the same privacy choice.

Browser and site limits

Remote sites can block pixel access with CORS. The image may still dispatch by URL, while local hashing, cropping, and provenance inspection remain unavailable for that source.

If a tab is blocked, its queue row remains visible with an Open / retry action. ImageXpert does not require permanent popup permission.
