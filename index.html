❓ How it works

🚀 Fully Automatic!
Drop images or a short video, then ImageXpert prepares URLs or extracted frames and opens the selected engines.

How the magic happens:

  1. You drop/paste images, URLs, or video
  2. Local files get hashes and optional preprocessing
  3. Video files become searchable keyframes
  4. Search engines open with URLs, hosted files, or manual upload pages

For URL images:

If you paste a URL, no upload needed — we pass the URL directly to search engines.

Privacy note:

Uploaded images are stored on litterbox.catbox.moe temporarily (1 hour) then auto-deleted. Enable no-upload dispatch to keep local files on this device and open manual engine upload pages instead.

Search engines:

  • Google Lens — Best for general recognition
  • Yandex — Great for finding higher res versions
  • Bing — Good for products
  • TinEye — Find where image appears online
  • SauceNAO — Best for anime/artwork
  • ASCII2D — Illustration and source lookup
  • TraceMoe — Anime frame lookup
  • IQDB variants — Booru-focused illustration lookup
  • PimEyes — Face search; use only with consent

⚠️ Popup blocker:

If only one tab opens, your browser is blocking popups. Click the blocked popup icon in your address bar and select "Always allow popups from this site". Then click "Search Again".
